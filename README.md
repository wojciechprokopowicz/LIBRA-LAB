# LIBRA Lab v20

LIBRA Lab is focused on personal wellbeing and Stress-Rest tracking.

## Main navigation
- **Home** — Stress-Rest Index, Advice and 7/30-day history.
- **Daily Input** — Today's Overview, Morning Check-in and Evening Check-in.
- **Calendar** — check-in history and imported Stress-Rest records.

The top-right menu contains Performance Mode, check-ins, CSV/PDF import, reports, backup/restore, settings and diagnostics.

## Removed from the active workflow
Practice Log, Add Activity, rehearsal/concert logging, Today's suggested direction and Weekly Plan have been removed from the visible interface. Existing stored records are retained and are not deleted.

## Index model
The new provisional LIBRA Lab index is based on:
- Morning: sleep duration, sleep quality, morning wellbeing and embouchure condition.
- Evening: evening wellbeing.
- A small carry-over from the previous evening's wellbeing.

Practice and work-event entries no longer influence the new index. Imported Stress-Rest history keeps its original historical index and source fields. This is a personal tracking heuristic, not a clinically validated score.

Before replacing files, export a LIBRA Lab backup. Upload all six files to the repository root and open with `?v=20`. Do not clear Safari website data.
